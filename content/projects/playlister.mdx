## Scope

A full-stack playlist management application built with React and Node.js, supporting dynamic
user interactions with real-time state synchronization.

## What it does

- **Client state.** Client-side state management handling complex UI behaviour — undo/redo,
  edit modals, and responsive components.
- **API.** RESTful endpoints in Express over structured MongoDB schemas, supporting playlist
  CRUD operations and embedded song data.

This was where state management stopped being a tutorial exercise: undo/redo forces you to
model every edit as a reversible operation rather than a mutation, and that changes how you
design the whole client.
